# FishBattle - 지역(Map) 데이터 기획서 (v1.0)

이 문서는 게임 내의 다양한 낚시터(지역) 정보와 이에 따른 기본 시스템 확률 밸런스를 정의합니다. 플레이어가 장비를 업그레이드하면서 순차적으로 상위 맵에 도전하는 성장 체감을 제공합니다.

---

## 1. 지역 설계 구조

각 지역은 다음과 같은 고유 데이터를 가집니다.

1. **지역 이름 / 테마**: 시각적, 청각적 피드백의 기준이 되는 테마.
2. **해금 조건**: 플레이어가 해당 지역에 진입하기 위해 충족해야 하는 골드 또는 선행 장비 스펙.
3. **대기 시간 (Waiting Time)**: 
   - `Min_Time`: 아이템으로도 줄일 수 없는 낚시 고유의 최소 대기 초.
   - `Max_Time`: 장비(미끼/낚싯줄 등) 성능에 의해 단축되는 최대 대기 초.
4. **희귀도 테이블**:
   - 물고기 등급: **일반(Common) / 희귀(Rare) / 전설(Epic)**
   - 지역별 기본 등장 확률 및 **최저 보장 확률(Floor)** 설정.

## 3. 확률 및 대기 시간 적용 메커니즘 예시

### 3.1. 대기 시간 계산 시나리오
* **예시 상황**: 플레이어가 **MAP_03 (안개 낀 망각의 늪)**에서 낚시를 진행하는 경우.
  - 늪의 기본 대기 시간: **Min 5초 / Max 15초**
  - 만약 플레이어가 장착한 낚싯대 장비가 `Max_Time -4초` 효과를 준다면:
    - 수정된 `Max_Time` = $15 - 4 = 11$초
    - 최종 낚시 대기 시간 범위 = `[5초 ~ 11초]` 사이에서 무작위 결정.
  - 만약 초고성능 장비를 장착하여 `Max_Time -12초` 효과를 준다면:
    - 계산상으로는 $15 - 12 = 3$초가 되나, 하한선 규칙에 의해 `Min_Time`인 **5초**보다 작아질 수 없습니다.
    - 이에 따라 최소 하한 보정인 `Min_Time + 1초`인 **6초**로 최종 `Max_Time`이 자동 보정됩니다. (최종 범위: `[5초 ~ 6초]`)

### 3.2. 희귀도 결정 시나리오
* **최종 희귀도 공식**:
  $$최종\ 확률 = \max(\text{지역 기본 확률} + \text{아이템 보정},\ \text{최저 보장 확률})$$
* **예시 상황**: **MAP_02 (파도치는 갈매기 해변)**에서 낚시 중. (전설 기본: 7%, 최저 보장: 2%)
  - **케이스 1 (성능 좋은 미끼 사용)**: 미끼 성능이 `전설 확률 +5%` 일 때
    - 최종 전설 확률 = $\max(7\% + 5\%,\ 2\%) = 12\%$
  - **케이스 2 (디버프 혹은 미끼 없음)**: 전설 확률 디버프 아이템 장착으로 인해 `전설 확률 -10%` 일 때
    - 계산상 전설 확률은 $7\% - 10\% = -3\%$가 되지만, 최저 보장 확률이 $2\%$이므로 최종 확률은 **2%**로 보정되어 최소한의 당첨 기회를 보장합니다.
